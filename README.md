"Sick Day" — a GTA 6 launch-day meme. After 13 years of waiting, Jason & Lucia take the convertible out on launch day, and the make.fun ghost rides in the back seat holding its magenta coin. The meme (`meme.png`, composed in-session by `compose.py` from the official press-kit ghost) is posted on X from a public account with make.fun and the account's play code in the post's text; `POST.json` names the post's address, and this program hands that file to the gate.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
